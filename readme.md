# 👑 EstateAI Royal - AI House Price Prediction System

An AI-powered Real Estate Valuation System built using Machine Learning and Streamlit.

The application predicts house prices using an XGBoost Regression model and provides an interactive luxury dashboard.

---

## 🚀 Features

- 🏠 House price prediction
- 👑 Premium royal UI dashboard
- 📸 Property image upload
- 💰 Price per square feet calculation
- 📊 Estimated market price range
- 🏡 Property category classification
- ⚡ Real-time prediction

---

## 🧠 Machine Learning

Model Used:

- XGBoost Regressor

Dataset:

- Housing Price Dataset

Features:

- Area
- Bedrooms
- Bathrooms
- Stories
- Parking
- Guest Room
- Basement
- Air Conditioning
- Preferred Area
- Furnishing Status
